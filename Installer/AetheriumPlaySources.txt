exact size and SHA-256 verification.

6. A09 ANTI-TAMPER DISCLOSURE

Aetherium Play checks active process/image names, exact top-level program
titles, and version-resource identity for common Cheat Engine builds before
launch, immediately after resume, and every two seconds while its client is
running. It resolves active executable full paths only to read version resources
and retains a bounded cache keyed by process start and file metadata in launcher
memory; full paths are not logged or uploaded. It also verifies the exact
in-memory regions installed by its own A09 client patch. It does not scan
directories, enumerate arbitrary modules, upload a process list, stop Cheat
Engine, or automatically ban an account. A violation prevents launch or ends
only the client.exe instance started by Aetherium Play. Forcibly ending the
launcher also ends that client. The reason is written locally to:

%LocalAppData%\AetheriumPlay\anti-tamper.log

This is a public, user-mode deterrent. It does not provide cryptographic proof
against a purpose-built modified client.
